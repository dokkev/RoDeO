Key Contracts

Contact gate

Force-aware runtime assumes tactile contact already exists. MPPIOptimizer is generic, so the caller/controller must gate no-contact observations before Update().

Tau semantics

Current-state tau is measured joint torque. Future rollout tau is a predicted commanded-torque proxy.

No heuristic proxy

The simple tactile proxy fallback is removed. Only force-aware rollout and explicit kinematic ablation remain.
