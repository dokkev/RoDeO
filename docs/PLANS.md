## Planning Rules

- Use a short inline plan for small changes.
- Create a durable plan for broad, ambiguous, risky, or multi-session work.
- Plans should include scope, non-goals, acceptance criteria, validation, and
  open questions.
- Update or close plans when implementation changes direction.
